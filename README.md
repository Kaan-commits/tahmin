# Süper Lig Tahmin Masası

https://tahmin.kaankara.com.tr

Haftalık Süper Lig maç tahminleri, sezon simülasyonu ve sanal kasa. Bu depo yalnızca yayınlanan site dosyalarını içerir
(`index.html` + haftalık güncellenen JSON verisi); model ayrı tutulur.

Bir veri projesidir, bahis tavsiyesi değildir. 18 yaşından küçükler bahis oynayamaz.
